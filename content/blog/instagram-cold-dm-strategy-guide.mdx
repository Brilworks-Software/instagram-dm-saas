# Instagram Cold DM Strategy That Actually Gets Replies

Cold messaging works if done correctly.

Most people fail because they focus on selling immediately.

## Rule 1: Keep It Short

Short messages get more replies.

Bad example:
- Long sales paragraph

Good example:
- Simple introduction
- Clear value
- Soft call to action

## Rule 2: Personalize Every Message

Mention something specific:

- Their niche
- Their page
- Their content

## Rule 3: Do Not Sell in First Message

Start conversation first.

Build trust before pitching.

## Rule 4: Follow Up Correctly

If no reply:

- Wait 2-3 days
- Send short follow-up
- Do not spam

## Final Thoughts

Cold DM works when it feels human.

Be clear. Be respectful. Be patient.
